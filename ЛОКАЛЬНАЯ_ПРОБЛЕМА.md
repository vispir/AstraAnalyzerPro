# Решение проблемы с Yahoo Finance

## Проблема
Ошибка: `'NoneType' object is not subscriptable` при запросе с `source=yfinance`

## Причина
Yahoo Finance API **заблокирован** на вашем локальном компьютере (региональные ограничения или firewall).

## Решение

### 🎯 Быстрое решение
В интерфейсе приложения выберите **"Twelve Data"** вместо "Yahoo Finance":

![image](https://github.com/user-attachments/assets/...)

Это выпадающий список справа в шапке приложения.

### 📝 Технические детали

**Frontend (App.jsx)**
```javascript
const [source, setSource] = useState('twelvedata');  // ✅ Уже правильно!
```

**Backend (market_routes.py)**
```python
source = request.args.get('source', 'twelvedata')  # ✅ Уже правильно!
```

По умолчанию используется Twelve Data. Проблема возникает только если **вручную** переключить на Yahoo Finance.

### ✅ Проверка
1. Откройте приложение
2. Убедитесь, что выбран источник **"Twelve Data"** (не "Yahoo Finance")
3. Графики должны загрузиться

### 🌐 Почему на сервере работает?
На удаленном сервере другой IP-адрес и регион, поэтому Yahoo Finance там доступен.

### 🔧 Если нужен именно Yahoo Finance
Используйте VPN с подключением к США/Европе.

## Статус
✅ Twelve Data API — **работает**  
❌ Yahoo Finance API — **заблокирован локально**  
✅ На удаленном сервере — **оба источника работают**
