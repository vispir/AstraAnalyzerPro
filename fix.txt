Необходимо внедрить функционал ручного задания локального 
диапазона через Telegram бота.

ЗАДАЧА 1 — Миграция БД (Supabase)

В таблице local_ranges добавить колонку:
    is_manual BOOLEAN DEFAULT FALSE

ЗАДАЧА 2 — db_service.py

Добавить следующие методы:

1. save_manual_range(symbol, timeframe, range_high, range_low)
   - Деактивировать все текущие активные диапазоны 
     (is_active=False, death_reason='replaced_by_manual')
   - Создать новый диапазон с is_manual=True, is_active=True
   - Вернуть id созданного диапазона

2. deactivate_manual_ranges(symbol)
   - Деактивировать все активные диапазоны где is_manual=True
   - death_reason='manual_deactivated'

3. has_active_manual_range(symbol)
   - Вернуть True если есть активный диапазон с is_manual=True

ЗАДАЧА 3 — watcher.py

В блоке где запускается calculate_local_range() 
(автоопределение диапазона) добавить проверку в начале:

    if db_service.has_active_manual_range(symbol="XAUUSD"):
        logger.info("📐 Ручной диапазон активен — 
                    автодетектор пропускается")
        # НЕ запускать calculate_local_range()
        # НЕ воскрешать старые диапазоны
        # Просто взять активный ручной диапазон из БД
    else:
        # обычная логика автодетектора

В блоке деактивации ручного диапазона — добавить вызов 
db_service.deactivate_manual_ranges() при следующих статусах:
    - is_range_breakout_confirmed = True 
      (BUY/SELL сигнал дан)
    - status = 'range_breakout_wait' 
      (WAIT от LLM при Range Breakout)
    - status = 'range_rejection_wait'
      (WAIT от LLM при Range Rejection)  
    - status = 'range_overheated'
      (перегрев фильтр)
    - status = 'htf_filter_blocked'
      (HTF фильтр заблокировал)

НЕ деактивировать при:
    - status = 'range_breakout_doji'
    - status = 'range_rejection_doji'
    (ждём третью свечу подтверждения)

В отчёте TG добавить пометку если диапазон ручной:
    "📐 Локальный диапазон (ручной ввод трейдера)"
    вместо обычного "📐 Локальный диапазон (БД)"

ЗАДАЧА 4 — telegram_bot.py (или где реализован TG бот)

Добавить две новые кнопки в главное меню бота:

Кнопка 1: "📐 Задать диапазон"
    - При нажатии бот отвечает:
      "Введите диапазон в формате: HIGH LOW
       Например: 5192 5175"
    - Парсить два числа из ответа пользователя
    - Валидация: HIGH > LOW, оба числа > 0
    - Вызвать db_service.save_manual_range()
    - Ответить: "✅ Диапазон задан: [{LOW} - {HIGH}]
                 Система будет торговать по нему."

Кнопка 2: "🔄 Авто режим"
    - При нажатии вызвать 
      db_service.deactivate_manual_ranges()
    - Ответить: "✅ Ручной диапазон деактивирован.
                 Система переходит в авто режим."

ВАЖНО:
- После деактивации ручного диапазона (любым способом) 
  is_manual=True остаётся в БД — не удалять запись.
  Диапазон участвует в воскрешении как обычный.
- Кнопки доступны только авторизованным пользователям бота.
- Добавить в SQL Supabase миграцию:
  ALTER TABLE local_ranges 
  ADD COLUMN IF NOT EXISTS is_manual BOOLEAN DEFAULT FALSE;
